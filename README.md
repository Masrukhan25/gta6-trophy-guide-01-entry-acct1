# Sunset Strip Platinum Run

A neon sunset GTA VI PS5 guide and local progress tracker: 55 researched trophies, cited instructions, source disagreements, character counters, session planning, share links, and a printable checklist. Serve `app/` with any static server. Run `MAKEFUN_OUTPUT_DIR=/tmp/trophy-out node main.ts` to package the entry. No build or runtime dependencies.
